# KGBone 화면 명세 (UI_SPEC)

근거: SOURCES.md S8~S11(사용 설명서의 화면 구성·도구·단축키 요약). 원래 프로그램을 쓰던 사람이 **같은 자리, 같은 단축키**로 쓸 수 있게 배치한다. 아이콘·이름·색은 새로 만들었다.
모든 화면 글자는 한국어. 메뉴·단축키·버튼은 전부 `interface/commands.json`에 정의된 같은 명령 id를 부른다(아래 표의 `명령`).

## 1. 전체 배치
```
┌───────────────────────────────────────────────────────────────────────┐
│ [≡ KGBone] 파일 편집 보기 만들기 애니메이션 도움말        제목: 이름.kgbone* │  메뉴 막대
├───────────────────────────────────────────────┬───────────────────────┤
│ [셋업 | 애니메이트]  (왼쪽 위, 모드 전환)       │  트리 (검색칸 포함)     │
│                                               │  - 뼈대                 │
│                 뷰포트 (WebGL2)                │    - 본 / 슬롯 / 첨부물  │
│                                               │    - 제약 / 스킨 / 이벤트 │
│                                               │    - 애니메이션          │
│ ┌───────────── 메인 도구 모음 (아래) ────────┐ ├───────────────────────┤
│ │포즈 가중치 생성│회전 이동 크기 기울기│로컬 부모 월드│ │  속성 (선택 항목)        │
│ └──────────────────────────────────────────┘ │                       │
├───────────────────────────────────────────────┴───────────────────────┤
│ 재생 막대: ⏮ ◀ ▶ ⏭ 반복 속도 시점  │ 도프시트 / 그래프 탭 (애니메이트 모드)     │
└───────────────────────────────────────────────────────────────────────┘
```
- 셋업 모드: 아래쪽 도프시트 영역이 접힌다(재생 막대는 숨김).
- 애니메이트 모드: 아래쪽에 재생 막대 + 도프시트/그래프 탭이 열리고, 뷰포트 테두리가 주황색이 된다.
- 상태 표시줄(맨 아래 한 줄): 선택 항목, 커서 월드 좌표, 확대 비율, AI 연결 상태(켰을 때만, 누르면 AI 연결 대화상자), 경고 수.

## 3. 메인 도구 모음 (뷰포트 아래쪽)
| 묶음 | 버튼 | 명령 | 단축키 |
|---|---|---|---|
| 도구 | 포즈 | tool.pose | B |
| | 생성(본 만들기: 빈 곳을 드래그) | tool.create | N |
| | 가중치(붓) | tool.weights | G |
| 변환 | 회전 | tool.rotate | C |
| | 이동 | tool.translate | V |
| | 크기 | tool.scale | X |
| | 기울기 | tool.shear | Z (KGBone 추가) |
| 축 | 로컬 / 부모 / 월드 | axis.local / axis.parent / axis.world | |
| 옵션 | 자식 보정 | option.compensate | |
- 이동 도구(V)로 본이 아닌 그림을 잡고 끌면 그 슬롯에 보이는 이미지 첨부물의 위치(x, y)만 옮긴다(셋업 모드, D14). Shift는 고른 축의 한 방향으로만. 애니메이트 모드나 이미지가 아닌 첨부물은 끌기를 시작할 때 이유를 알린다. Ctrl/Shift+클릭은 선택만 한다.
- 뷰포트를 오른쪽 클릭하면 현재 도구와 직전 도구가 바뀐다(S9).
- 휠: 확대·축소, 가운데 버튼 드래그 또는 Space+드래그: 화면 이동.

## 4. 트리 (오른쪽 위)
- 맨 위 검색칸(Ctrl+F). 한국어 입력 가능.
- 노드: 뼈대 › 본(계층) › 슬롯 › 첨부물 / 제약 / 스킨 / 이벤트 / 애니메이션.
- 표시 켜기(눈) 아이콘, 키 표시(애니메이트 모드에서 현재 시점에 키가 있으면 표시).
- 슬롯을 끌어서 그리기 순서 변경(`slot.reorder`), 본을 끌어서 부모 변경(`bone.setParent`).
- 더블클릭 또는 F2: 이름 바꾸기.

## 5. 속성 (오른쪽 아래)
선택 항목 종류별:
- 본: 이름, 부모, 위치 X/Y, 회전, 크기 X/Y, 기울기 X/Y, 길이, 상속(드롭다운), 색상, 스킨 필요.
- 슬롯: 이름, 본, 색상, 어두운 색(켜기+색), 블렌드(드롭다운), 셋업 첨부물.
- 첨부물: 종류별 필드(이미지: 경로·위치·회전·크기·폭·높이 / 메시: 정점 편집 켜기, 자동 생성, 바인딩, 자동 가중치 / 클리핑: 끝 슬롯·반전·볼록 / 패스: 닫힘·일정 속도).
- 제약: 종류별 필드(IK: 본·목표·혼합·부드러움·굽힘·압축·늘이기·균등·부피 보존 / 트랜스폼: 원본·로컬 원본·로컬 대상·더하기·범위 제한·혼합 6개·속성 매핑 표 / 패스 / 물리 / 슬라이더: 애니메이션·시점·반복·더하기·혼합·본·속성·범위).
- 스킨, 이벤트(정수·실수·문자열·오디오·볼륨·균형), 애니메이션(이름, 길이 표시).
- 모든 숫자칸은 수식 입력 가능: `v*2`, `value+10`, `+=5`, `-=5`, `*=2`, `/=2`, 괄호·사칙연산. Enter로 확정, Esc로 취소.
- 숫자칸 라벨을 좌우로 끌면 값이 바뀌고, 끌기 한 번이 되돌리기 한 번.

## 6. 재생 막대 + 도프시트 + 그래프 (아래, 애니메이트 모드)
- 재생 막대: 처음, 거꾸로 재생, 재생/정지, 끝, 반복 켜기, 속도(0.1~4배), 현재 시점(프레임/초).
- 애니메이션 고르기 드롭다운.
- 도프시트: 왼쪽 줄 이름(본/슬롯/제약 → 타임라인), 오른쪽 프레임 눈금과 키 마름모. 클릭 선택, Shift 추가 선택, 드래그로 키 이동, Delete로 삭제, Ctrl+C/Ctrl+V 복사·붙여넣기. 눈금 클릭으로 시점 이동.
- 그래프: 선택한 타임라인의 값 곡선, 베지어 손잡이 드래그. 위쪽 버튼: 선형 / 계단 / 베지어.
- 오니언 스킨 설정: 앞·뒤 프레임 수, 간격.

## 7. 대화상자
- 저장하지 않은 변경이 있을 때 닫기·새로 만들기·열기: "저장하지 않은 변경이 있습니다. 저장할까요?" [저장] [저장 안 함] [취소].
- 내보내기(Spine JSON 호환): 출력 폴더, 버전(4.3 / 4.2), 보기 좋게 출력, 아틀라스 최대 크기, 여백. 4.3 미확인 항목 경고 목록 표시.
- PNG 시퀀스: 애니메이션, fps, 크기, 배율, 배경 투명.
- AI 연결(도구 메뉴): 상태(꺼짐·연결하는 중·연결됨·AI 프로그램을 기다리는 중), 붙은 AI 이름, 최근 작업, 포트(기본 47821), 창을 열 때 자동으로 연결, [연결]/[연결 끊기]. 메시지 형식은 `interface/agent-link.md`.

## 8. 한국어 입력
- 모든 입력칸은 IME 조합 중(`compositionstart`~`compositionend`, `isComposing`)에는 단축키를 처리하지 않는다.
- 단축키 처리는 입력칸에 초점이 있으면 Ctrl/Alt 조합과 Esc·Enter만 처리한다.
