## 4. 실행 파일
- CI가 main push마다 빌드해 `build-output` 브랜치에 올린다. `acae8be` 빌드: 성공(2026-11-17 12:16 UTC), `KGBone.exe` 5,100,544바이트, SHA-256 `7d04b0ca6513090d4ac12a38e1e61176b8a47adca0633b889a160a1e133c45c2`.
- 받기: `git fetch origin build-output` 후 `git show origin/build-output:KGBone.exe > dist-exe/KGBone.exe` (`dist-exe/`는 커밋하지 않음).
- **서명이 없다.** 처음 실행하면 Windows SmartScreen 경고("Windows의 PC 보호")가 뜬다 → [추가 정보] → [실행]. 스마트 앱 컨트롤이 켜진 PC(이 PC)에서는 실행이 막히므로 웹 판을 쓴다: https://dudwo2199.github.io/KGBone/ (Edge에서 "앱 설치").
