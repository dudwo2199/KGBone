## Spine 4.3 JSON 호환 미확인
- **G-10** 트랜스폼 제약 4.3 표기(속성 매핑·범위 제한·로컬/월드 분리)의 JSON 키 이름 미확인. 내보내기는 4.2 표기(`mixRotate`, `offsetX` 등)로 표현 가능한 경우만 내보내고, 그 밖의 매핑은 경고 후 4.2 표기로 근사하거나 생략한다.
- **G-11** 슬라이더 제약의 JSON 표기 미확인 → Spine JSON 내보내기에서 제외하고 경고. .kgbone에는 모두 저장된다.
- **G-12** IK·물리의 부피 보존(scaleY) JSON 키 미확인 → 내보내기에서 제외하고 경고.
- **G-13** 4.3 JSON의 "가독성·크기·정밀도 개선"(S4)이 구체적으로 무엇인지 미확인 → 4.2 문서 구조로 읽고, 모르는 키는 보존만 한다.
- **G-14** atlas 회전 영역의 `bounds` 폭·높이를 "페이지에 놓인 그대로"로 해석(90·270도면 원래 방향으로 바꿔 보관). 공개 아틀라스 문서로 확인 못 함.
- **G-15** Spine 키 값이 생략됐을 때의 기본값 일부 미확인: alpha 1, scale·scalex·scaley 1, 물리 mix 1·그 밖 0, 시퀀스 mode "hold". 읽기·쓰기는 서로 맞춰 둠.
- **G-16** 클리핑 `inverse`·`convex`(4.3)의 JSON 키 이름 미확인 → 켜졌을 때만 이 이름으로 씀.

## Spine JSON 호환 알려진 한계
- 첨부물에 Spine `name`과 `path`가 둘 다 있으면 모델에는 `path`만 남는다.
- 슬롯 `visible`은 Spine JSON으로 주고받지 않는다. 가져온 문서를 내보내면 `skeleton.images`는 원본 값이 유지된다.
- 모르는 종류의 첨부물은 경고만 내고 읽지 않으며, 내보낼 때 사라진다.
