## 8-1. 단축키 전체

글자 단축키는 한글 자판 상태에서도 같은 자리의 키로 동작합니다. 글자 입력칸에 초점이 있을 때와 한글 조합 중에는 단축키가 동작하지 않습니다(Ctrl·Alt 조합과 Esc·Enter만 동작).

### 파일

| 키 | 동작 |
|---|---|
| Ctrl+N | 새로 만들기 |
| Ctrl+O | 열기 |
| Ctrl+S | 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |
| Ctrl+I | Spine JSON 호환 가져오기 |
| Ctrl+E | Spine JSON 호환 + 아틀라스 내보내기 |
| F5 | 이미지 다시 불러오기 |

### 편집

| 키 | 동작 |
|---|---|
| Ctrl+Z | 되돌리기 |
| Ctrl+Y, Ctrl+Shift+Z | 다시 실행 |
| Delete | 삭제(도프시트에서는 고른 키 삭제, 정점 편집 중에는 고른 정점 삭제) |
| F2 | 이름 바꾸기 |
| Ctrl+D | 복제(애니메이션) |
| P | 부모 지정(다음에 클릭한 본이 새 부모) |
| + (또는 =) | 그리기 순서 앞으로 |
| - | 그리기 순서 뒤로 |
| Esc | 선택 해제 / 정점 편집·부모 지정 취소 |
| Ctrl+F | 트리 검색 |

### 보기

| 키 | 동작 |
|---|---|
| Ctrl+= / Ctrl+- | 확대 / 축소 |
| Home | 화면 맞춤 |
| Ctrl+0 | 실제 크기 |
| O | 오니언 스킨 |

### 도구

| 키 | 도구 | 키 | 도구 |
|---|---|---|---|
| B | 포즈 | C | 회전 |
| N | 생성(본 만들기) | V | 이동 |
| G | 가중치 붓 | X | 크기 |
| Ctrl+Shift+N | 본 만들기(고른 본의 자식) | Z | 기울기 |

### 애니메이션

| 키 | 동작 |
|---|---|
| Tab | 셋업 ↔ 애니메이트 모드 |
| D | 재생 / 정지 |
| A | 거꾸로 재생 |
| , / . | 이전 / 다음 프레임 |
| Alt+, / Alt+. | 이전 / 다음 키 |
| Ctrl+Home / Ctrl+End | 처음 / 끝 |
| K | 고른 본·슬롯의 지금 값을 키로 |
| Shift+K | 제약 적용 결과를 키로 |
| Ctrl+Shift+L | 모든 본의 지금 값을 키로 |
| Ctrl+C / Ctrl+V | (도프시트) 키 복사 / 지금 시점에 붙여넣기 |

### 도움말

| 키 | 동작 |
|---|---|
| F1 | 단축키 목록 |

## 8-2. 마우스 조작

| 곳 | 조작 | 동작 |
|---|---|---|
| 뷰포트 | 휠 | 확대·축소 |
| 뷰포트 | 가운데 버튼 끌기 / Space+왼쪽 끌기 | 화면 이동 |
| 뷰포트 | 왼쪽 클릭 | 본·그림 고르기(Ctrl·Shift: 여러 개) |
| 뷰포트 | 오른쪽 클릭 | 지금 도구 ↔ 직전 도구 |
| 뷰포트 | 이동 도구로 그림 끌기 | 그림(첨부물)만 옮기기(셋업 모드, 이미지 첨부물) |
| 뷰포트 | 도구 + Shift 끌기 | 회전·기울기 15도 단위, 이동 한 방향, 크기 같은 비율 |
| 뷰포트 | 가중치 붓 + Alt 끌기 | 가중치 빼기 |
| 트리 | 더블클릭 | 이름 바꾸기 |
| 트리 | 오른쪽 클릭 | 그 항목의 메뉴(만들기, 이름 바꾸기, 삭제, 스킨 사용, 애니메이션 고르기 …) |
| 트리 | 본 끌어 놓기 | 부모 바꾸기 |
| 트리 | 그리기 순서의 슬롯 끌어 놓기 | 그리기 순서 바꾸기 |
| 트리 | 눈 아이콘 | 숨기기 / 보이기 |
| 속성 | 숫자칸 이름(라벨)을 좌우로 끌기 | 값을 조금씩 바꾸기(끌기 한 번 = 되돌리기 한 번) |
| 도프시트 | 눈금 클릭 | 시점 이동 |
| 도프시트 | 키 클릭·끌기 | 고르기·옮기기 |
| 그래프 | 손잡이 끌기 | 베지어 곡선 다듬기 |

## 8-3. 숫자 입력칸 수식

속성 패널의 모든 숫자칸에는 계산식을 쓸 수 있습니다. **Enter**로 확정, **Esc**로 취소합니다.

| 입력 | 결과(지금 값이 10일 때) |
|---|---|
| `25` | 25 |
| `+=5` | 15 |
| `-=5` | 5 |
| `*=2` | 20 |
| `/=2` | 5 |
| `v*2` 또는 `value*2` | 20(`v`·`value`는 지금 값) |
| `(1+2)*3` | 9 |

본을 여러 개 고를 필요 없이, 같은 값을 정확히 더하거나 비율로 바꿀 때 편합니다.

## 8-4. 자주 묻는 것

**그림이 안 보여요.**
- 트리의 **이미지** 폴더에 그림이 있는지 보세요. 비어 있으면 이미지 폴더 경로가 맞지 않는 것입니다(**파일 → 이미지 폴더 지정**).
- 웹 앱에서는 프로젝트를 열 때 **프로젝트 파일이 있는 폴더**를 골라야 이미지 폴더를 읽을 수 있습니다.
- 슬롯의 **셋업 첨부물**이 **(없음)**이 아닌지, 트리의 눈 아이콘이 꺼져 있지 않은지 보세요.
- 그림을 고친 뒤라면 **F5**.

**본을 클릭하려는데 그림이 잡혀요 / 그림을 끌려는데 본이 잡혀요.**
본이 우선으로 잡힙니다. 본을 숨기려면 **보기 → 본 표시**를 끄세요. 그림을 숨기려면 **보기 → 이미지 표시**를 끕니다.

**애니메이트 모드에서 그림 위치를 옮길 수 없어요.**
첨부물 위치는 키가 되지 않습니다. 본을 움직이거나(본이 키가 됨), 메시라면 정점을 옮겨 변형 키를 만드세요.

**메시 정점을 추가할 수 없어요.**
가중치 메시(바인딩한 메시)는 정점 수를 바꿀 수 없습니다. **바인딩 해제** 후 고치고 다시 바인딩하세요. 애니메이트 모드에서도 추가·삭제는 안 되고 끌기만 됩니다.

**가중치 붓이 칠해지지 않아요.**
메시 첨부물과 칠할 본을 **함께** 골라야 합니다(트리에서 첨부물 클릭 → Ctrl+본 클릭).

**물리 제약이 안 움직여요.**
물리는 재생할 때 계산됩니다. 애니메이트 모드에서 **D**로 재생하세요.

**저장한 파일을 다른 PC로 옮겼더니 그림이 없어요.**
`.kgbone`에는 그림이 들어 있지 않습니다. `images` 폴더도 같은 상대 위치에 함께 옮기세요.

**아직 안 되는 기능은?**
[docs/GAPS.md](../docs/GAPS.md)에 정리되어 있습니다.
